# 🚀 ES6 Modules Classwork

This repository serves as a **Classwork** project dedicated to mastering the core syntax of **ES6 Modules**, demonstrating **named** and **default** `export` types, and various **`import`** methods for structuring Vanilla JavaScript code. To run this module-based project, a **local HTTP server is required**, and all operational results are visible in the browser's Developer Console.
